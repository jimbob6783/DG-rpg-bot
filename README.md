# 🥏 Disc Golf RPG Bot  
### A Cinematic, Hazard-Filled RPG Experience Inside Discord  
Fully Developer-Friendly Version (with comments)

This project is a full-scale RPG game built entirely inside Discord.  
Players create characters, assign stats, buy discs, level up, and play through cinematic disc golf courses filled with hazards, wildlife, chaotic events, and brutal weather.

This is the **developer edition**, including:  
✔ Full comments in every file  
✔ Dev-only commands   
✔ Achievements system  
✔ Prestige system  
✔ Daily quests  
✔ Seasonal weather  
✔ Hazard scaling  
✔ Inventory + shop  
✔ Physics + narration engine  
✔ MongoDB models  
✔ Full modular command architecture  

---

# 🎮 Core Features

## 🧬 Character System
- Create unique character names  
- Assign stats (STR, SPD, TEC, STA, FOC)  
- Earn XP, level up  
- Prestige & unlock bonus stat points  

## 🥏 Throwing System
- Accurate simulated disc physics  
- Cinematic narration per throw  
- Brutal hazard engine (trees, cliffs, rivers, boulders)  
- Wildlife encounters (geese, deer, bears)  
- Vehicle collisions (urban course)  
- Putting mechanics for <60 ft  

## 🌦 Weather System
- Random weather per hole  
- Seasonal modifiers (month-based)  
- Rain, wind, temperature, ground softness  

## 🗺️ Courses
Includes 6 handcrafted courses:
- Elderwood Meadows  
- Ironpine Ridge  
- Sunforge Dunes  
- Stormbreach Cove  
- MetroPark Circuit  
- Frostpeak Valley  

Each with:
- Distance  
- Par  
- Terrain risks  
- Hazard multipliers  

## 🧰 Inventory + Shop System
- Buy discs  
- Equip discs  
- Earn coins via achievements  

## 🧾 Scorecard + Export
- Scorecard embeds  
- Export scorecards as `.txt`  

## 🏆 Tournament Mode
- Multiplayer foundation (beta)
